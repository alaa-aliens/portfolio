[Carseer](/work/carseer) sells one thing: the truth about a used car. But the website buried that behind marketing pages, and the report itself read like a database dump, so buyers had to decode it instead of deciding.

The brief was two redesigns in one: a website that moves from VIN to report with nothing in between, and a report a nervous buyer can read on a phone in a car park.

## Seventeen characters, seventeen clicks

A VIN is 17 characters. The old site needed about 17 clicks after you typed it. We fixed the clicks.

Every page now opens with the same question: what's the car? VIN or plate, one field, one button. The marketing moved below it. There was a small fight with the marketing page. The field won.

## The report was the product

The website was the easy part. The report was the product, so we pulled it out as its own redesign with its own rule: verdict first, evidence second.

The new report opens with a verdict strip: accidents, odometer, title, recalls, each with a plain state. Below it, the full history as a timeline rather than a table. It felt like translating. The data was there; it just didn't speak.

## Give one colour one job

The warm palette carries the brand, but orange is reserved for one job: the things you should look at. If everything is highlighted, nothing is. A worried person scanning a report needs the eye to land in the right place on the first try.

## Write packages for situations

Pricing used to be a feature grid. Now each package is written for a situation: "I'm looking at one car", "I'm shopping around", "I sell cars". The differences are three lines, not thirty. People were sceptical at first. Then the copy got simpler and it clicked.

## Design the page people come back to

Shopping for a car takes weeks and several candidates. "My Garage" keeps every checked car in one place with its verdict, so comparing is a glance instead of a folder of PDFs. It's the page people return to, so it got the same care as the report.

> A history report is a stressful document. The job wasn't making it pretty; it was making a worried person feel they'd understood it the first time.
