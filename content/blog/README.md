# How to add a blog post

1. Make a new file in this folder. The file name becomes the address:
   `my-new-post.md` → alaa-ali.com/blog/my-new-post/
2. Start it with this block, then write the post below it:

```
---
title: The title of the post
description: One sentence that shows under the title and in Google / link previews.
date: 2026-10-20
lang: en            (or ar for Arabic — the page flips to right-to-left)
cover: family       (name of one of your drawings, see below)
tags: ux, kids
draft: true         (true = only on the hidden v2 site; false = public)
---
```

3. Write normally. `## ` makes a heading, `> ` makes a hand-drawn quote box,
   `- ` makes a list, `**bold**`, `[link text](https://…)`, `---` makes a divider.

Drawings you can use as `cover`: books, couch1, family, news, site, teach (+ -b / -c
versions), carseer, siba-list, trackhawk, contact, designer, teacher, consultant, creator, father.

Each post automatically gets its own page, title, Google description, share preview
and a place in the sitemap.
